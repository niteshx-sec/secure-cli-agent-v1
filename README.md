# Secure-CLI-Agent-v1: Production-Grade Autonomous ReAct Agent

An autonomous Command-Line AI Agent built from scratch in pure Python with active security guardrails, designed to defend against common Large Language Model vulnerabilities (OWASP Top 10 for LLMs).

Unlike conventional agentic frameworks that act as black boxes, this architecture provides complete visibility and enforcement at the parameter, execution, and state layers.

---

## Key Architecture & Core Capabilities

- **Autonomous ReAct Reasoning Loop:** Implements the Reason-Act-Observe cycle without third-party agent framework bloat (no LangChain, no CrewAI).
- **Strict Parameter Validation:** Every tool execution request generated by the model is intercepted and validated against strict Pydantic v2 schemas before execution.
- **Resource Depletion Defense (Circuit Breaker):** Bounded `while` execution loops enforce hard step limits to prevent wallet exhaustion and infinite reasoning loops (OWASP LLM04).
- **Encapsulated State Isolation:** Instance-level memory boundaries ensure multi-tenant security and zero state contamination across sessions (OWASP LLM06).
- **Extensible Dynamic Dispatcher:** A modular tool registry pattern enabling deterministic tool calling via OpenAI/Groq function calling protocols.

## Threat Model & OWASP LLM Mitigations

| Vulnerability | Threat Description | Architectural Mitigation |
| :--- | :--- | :--- |
| **OWASP LLM01: Prompt Injection** | Malicious payloads attempting to hijack execution or bypass constraints. | Content-level regex whitelisting and Pydantic field validators strip/reject malicious inputs. |
| **OWASP LLM04: Resource Exhaustion** | Recursive reasoning loops draining API credit balances and hanging threads. | Algorithmic Circuit Breakers enforce maximum reasoning steps (`max_steps=4`) with fail-safe aborts. |
| **OWASP LLM06: Sensitive Disclosure** | Leaking private credentials or cross-session conversation states. | Name-mangled private variables (`__api_key`), read-only property getters with masking, and strict `.env` isolation. |
| **OWASP LLM08: Excessive Agency** | Model generating arbitrary code or executing unauthorized tools. | Whitelisted tool registry (`AgentToolDispatcher`) drops unregistered and out-of-bound calls instantly. |

## Quickstart & Installation

### 1. Clone Repository & Setup Virtual Environment
```bash
git clone https://github.com
cd secure-cli-agent-v1
python -m venv venv

# On Windows:
venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Configure Secrets
Create a `.env` file in the root directory (refer to `.env.example`):
```bash
cp .env.example .env
```
Add your Groq API key:
```text
GROQ_API_KEY="your-groq-api-key-here"
```

### 4. Run the Agent
```bash
python main.py
```
